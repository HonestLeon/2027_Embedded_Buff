# 代码重构实施计划（2027 主机固件）

> 依据：《代码架构设计.md》（定稿）、《重构对照-旧代码与新设计.md》（标定核对表）、《主机CubeMX配置清单.md》
> 工程基线：`2027_Embedded_Buff/2027_Embedded_Buff_Master/`（CubeMX 已生成、NVIC/调度入口已核对）
> 目标：按架构文档落地全部代码，**行为对齐 2025 老固件 + 修复已知四个老 bug**
> （灯带只刷一次 / DMA 重启撞车花屏 / 复位段裕量 / 上电色序异常）

---

## 一、总体策略

1. **自底向上**：config → bsp → application，每层完成即编译烧录验证，不攒大爆炸；
2. **每阶段有硬验收**：通不过不进下一阶段（验收标准全部可上板执行）；
3. **标定值单一来源**：所有老代码数值迁移以《重构对照》第 9 节核对表为验收依据，
   填一项勾一项；
4. **并行机会**：阶段 4（CAN）与阶段 2/3（WS2812）互不依赖，可并行。

```
P0 工程接入 ──► P1 config ──► P2 bsp_ws2812 ──► P3 白光测试+light ──► P6 buff状态机 ──► P7 整机联调
                                    │                                    ▲
                                    └──（可并行）──► P4 bsp_can+协议 ──► P5 motor ──┘
```
